# Снежок ❄️

Android-приложение, которое рисует снег поверх главного экрана: сугроб внизу,
гирлянда в строке состояния, экскаваторы, банка колы и снежки,
которые лепятся прямо из сугроба: из них можно собрать снеговика или бросить, и снежок рассыплется.
Плитка «Снег» в шторке включает и выключает всё одним касанием.

## Скачать

Готовый APK — в разделе **Releases** (`Snezhok.apk`). Он пересобирается
автоматически после каждого изменения в ветке `main`.

> Если ставили версию, собранную до перехода на постоянный ключ подписи,
> удалите её один раз. Дальше обновления ставятся поверх.

## Структура

```
src/main/java/ru/opsel/snezhok/App.java   весь код приложения
src/main/AndroidManifest.xml               манифест
src/main/res/drawable/                     иконки
build.gradle, settings.gradle              настройки сборки
debug.keystore                             ключ подписи (чтобы обновления ставились поверх)
.github/workflows/sborka.yml               сборка APK в GitHub Actions
```

## Как вносить изменения

Удобнее всего править `src/main/java/ru/opsel/snezhok/App.java` прямо на GitHub.

Старый способ тоже работает: если загрузить в корень репозитория `App3.java`
(или `AndroidManifest2.xml`), сборка возьмёт файл с самым большим номером вместо
файла из `src/main`. Не забудьте потом удалить такие файлы из корня, иначе правки
в `src/main` будут игнорироваться.

## Сборка локально

Нужны JDK 17, Gradle 8.7 и Android SDK (platform 34):

```
gradle assembleDebug
```
